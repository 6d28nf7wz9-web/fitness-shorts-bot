# SVG + WebGL muscle mechanics prototype

An isolated, free, dependency-free experiment inspired by the MIT-licensed Anatomy skill. SVG owns the solids, labels and callouts; a transparent WebGL fragment shader adds a restrained contraction/tension field. SVG remains the fallback if WebGL is unavailable.

Comparison prototype only: it does not replace Blender, is not wired into publishing, and makes no clinical-accuracy claim. No API keys, paid services, external assets or runtime network requests. Open index.html in a modern browser with WebGL enabled.
